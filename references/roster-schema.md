# 成绩表 xlsx 格式说明 ｜ Roster Schema

`scripts/generate.py` 读取的成绩表需为 `.xlsx` 格式，工作表遵循下述结构。

## 总体结构

```
第 1 行（或前若干行）  可选：标题行，含班级名，如 "高二(5)班 · English Learning Roster"
第 2 行              可选：副标题，如 "40 students · Senior 2 · 12-week plan"
第 3 行              表头行
第 4 行起            学生数据行
```

脚本会**自动定位表头行**（在前 20 行内查找同时含 `ID` 与 `Name` 的行），因此标题行可有可无、行数可变。

## 列定义（从 A 列起，顺序固定）

| 列 | 表头示例 | 类型 | 说明 |
|---|---|---|---|
| A | `ID` | 字符串 | 学号，需匹配 `^[A-Za-z]*\d+$`（如 `S01`）才被识别为学生行 |
| B | `Name 姓名` | 字符串 | 学生姓名 |
| C | `Tier` | 字符串 | 分层标记：`A+` / `A` / `B` / `C` |
| D | `Score 当前` | 整数 | 当前总分（满分 150） |
| E | `Target` | 整数 | 高考目标分 |
| F | `Vocab` | 整数 | 当前词汇量 |
| G | `Target` | 整数 | 词汇量目标（通常 5500） |
| H | `🎧 Listening` | `23/30` | 听力当前得分 / 满分 |
| I | `Target` | `28/30` | 听力目标得分 |
| J | `📖 Reading` | `31/40` | 阅读当前得分 / 满分 |
| K | `Target` | `35/40` | 阅读目标得分 |
| L | `✍️ Writing` | `16/25` | 写作当前得分 / 满分 |
| M | `Target` | `20/25` | 写作目标得分 |
| N | `⚠️ 弱项` | 字符串 | 弱项诊断：`Writing` / `Listening` / `Reading` |

## 分项格式

听力、阅读、写作三列使用 `当前分/满分` 格式，脚本用正则解析：

```python
re.match(r"\s*(\d+)\s*/\s*(\d+)", "23/30")  # -> (23, 30)
```

`当前分` 列的第二个数字即满分，用于计算班级达标率；`目标` 列只需第一个数字。

## 弱项取值

只接受三种值，脚本会原样保留：

| 值 | 含义 |
|---|---|
| `Writing` | 写作弱项 |
| `Listening` | 听力弱项 |
| `Reading` | 阅读弱项 |

其他值（含空值）会被归为 `Writing`。

## 最小可用示例

只需 A–N 列齐全、表头行可识别即可。数据行之间允许有空行，脚本会自动跳过。

| ID | Name 姓名 | Tier | Score 当前 | Target | Vocab | Target | Listening | Target | Reading | Target | Writing | Target | 弱项 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| S01 | 何丽 | B | 123 | 131 | 4643 | 5500 | 23/30 | 28/30 | 31/40 | 35/40 | 16/25 | 20/25 | Writing |
| S02 | 杨明 | A | 130 | 138 | 3350 | 5500 | 25/30 | 30/30 | 35/40 | 40/40 | 20/25 | 24/25 | Writing |

## 班级名识别

脚本在前 5 行内用正则匹配班级名：

```python
r"([\u4e00-\u9fff]{1,6}\(\d+\)班|[\u4e00-\u9fff]{2,8}班)"
```

即 `高二(5)班`、`高三(1)班`、`高二英语班` 等形式均可。识别失败时可用 `--class-name` 手动指定。

## 多工作表

脚本默认读取**第一个工作表**。若成绩表有多个 sheet，把目标 sheet 放到第一位，或拆分后单独运行。
