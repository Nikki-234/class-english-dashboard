一个面向英语教师的**单文件 HTML 班级学情仪表盘生成工具**：准备好成绩表 xlsx，运行一条命令，即可生成功能完整的仪表盘网页——教师用浏览器打开即可编辑数据、追踪每个学生的学习进度。

## 在线体验（无需安装）

直接访问上方任一链接即可。页面功能：

| 模块 | 说明 |
|---|---|
| KPI 条 | 均分、中位、极差、σ、A+ 区 / C 区人数、距高考目标差、Tier 分布 |
| 分数段分布 | 4 个分数段横向条，颜色对应 Tier 色板 |
| 四项分项达标率 | 听 / 读 / 写 / 词，含 80% 目标线 |
| 弱项分布 | 按 Writing / Listening / Reading 分组计数 |
| 本周班级进度 | 汇总教师在抽屉中填入的完成百分比 |
| 学生名单表 | 40 行 × 12 列，**单元格可直接编辑**（按角色受限） |
| 12 周进度趋势 | 手绘 SVG 折线图，听/读/写/词四线 + 周次切换 |
| 详情抽屉 | 学习进度 / 提升策略 / 教师备注 / 留言板 四 Tab |
| 交互 | 搜索、Tier 筛选、5 种排序、面板拖拽排序 |
| 持久化 | localStorage 自动保存 |
| 备份 | JSON 导入导出、一键重置 |

**操作方式**：单击可编辑单元格进入编辑（Enter 确认 / Esc 取消 / 失焦自动保存）；点击行空白处打开该学生详情抽屉。修改任一单元格后，KPI 条、分数段、四项达标率、班级进度会**立即重算**。

### 个人化定制

每个人首次打开会创建自己的档案，设置**只保存在各自浏览器**，互不影响。

| 角色 | 看到什么 | 能做什么 |
|---|---|---|
| **老师** | 全班 40 人完整数据 | 编辑全部学生成绩与进度、回复留言、查看群体统计 |
| **学生** | 仅本人记录（大卡片 + 详情抽屉） | 更新自己的各科进度、查看提升策略、给老师留言 |
| **家长** | 仅孩子记录 | 查看孩子成绩详情、弱项诊断、学习进度、给老师留言 |

**权限粒度**：学生/家长只能修改自己（或孩子）的**各科进度**与**留言**，分数、目标分、姓名、Tier 一律锁定（表格里显示斜纹底纹 + 🔒 提示）；老师不受限制。

**12 周进度追踪**：每个学生有 12 周记录明细表，可逐周填写听/读/写/词完成度。顶栏「第 N 周」徽章可点击切换当前周，趋势图只统计到当前周。

**留言板**：学生/家长在详情抽屉的「留言板」里留言，老师可逐条回复。未回复的条数显示在 tab 徽章上。

**个性化设置**（顶栏「个性化设置」或右下角「设置」）：

- 显示哪些面板 — KPI 数字条 / 分数段分布 / 四项达标率 / 弱项分布 / 班级进度 / 12 周趋势 / 学生名单，任选开关
- 面板顺序 — 设置面板里用 ↑↓ 调序，也可直接拖动面板右上角的手柄
- 数据细节 — 是否显示目标分、是否显示差距、是否显示教师备注、**姓名匿名化**（一键换成「学生01」编号）
- 计划周次 — 切换当前处于第几周
- 外观 — 5 种主题（暖色 / 薄荷 / 天蓝 / 纯白 / **高对比投影**）× 3 档信息密度（紧凑适合投影 / 标准 / 宽松）

**状态分享**：在设置面板点「复制当前状态链接」，会把当前数据 + 显示偏好 + 身份一起编码进网址。对方打开该链接即自动恢复你的视图——适合把「只看我关心的面板」的配置发给同事。

## 本地生成（用于其他班级）

需要 Python 3 和 `openpyxl`：

```bash
pip3 install openpyxl

# 生成仪表盘
python3 scripts/generate.py 成绩表1.xlsx 高二5班仪表盘.html

# 自定义标题与班级名
python3 scripts/generate.py 成绩表1.xlsx 输出.html --class-name "高二(5)班" --title "高二(5)班英语学情看板"
```

生成的 HTML 用浏览器打开即可，无需服务器、无需联网。

## 成绩表格式

见 [references/roster-schema.md](references/roster-schema.md)。核心要求：

- 表头行含 `ID` 与 `Name` 两列（脚本在前 20 行内自动定位）
- A–N 列顺序固定：ID / 姓名 / Tier / 当前分 / 目标分 / 词汇 / 词汇目标 / 听 / 听目标 / 读 / 读目标 / 写 / 写目标 / 弱项
- 分项用 `23/30` 格式，弱项用 `Writing` / `Listening` / `Reading`
