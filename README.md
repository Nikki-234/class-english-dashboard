# 高二(5)班 · 英语学习仪表盘

一个**单文件 HTML** 的班级英语学情仪表盘,基于 `成绩表1.xlsx` 的 40 名学生数据构建。

## 功能

- **KPI 条** — 班级平均、中位数、极差、标准差、A+ 区 / C 区人数、距高考目标差、Tier 分布
- **分数段分布** — 按 4 个分数段(≥135 / 125-134 / 115-124 / <115)切分,颜色对应 Tier
- **四项分项达标率** — 听 / 读 / 写 / 词,含 80% 目标线
- **弱项分布** — 写作 25 人(62.5%)是班级最大瓶颈
- **学生名单表** — 40 行 × 12 列,**单元格可直接编辑**
- **本周班级进度** — 汇总教师在抽屉中填入的完成百分比
- **学生详情抽屉** — 三个 Tab:学习进度 / 提升策略 / 教师备注
- **搜索 / Tier 筛选 / 排序**
- **数据持久化** — localStorage 自动保存
- **JSON 导入导出 / 一键重置**

## 交互说明

| 操作 | 效果 |
|---|---|
| 单击可编辑单元格 | 进入编辑(输入框或下拉) |
| Enter | 确认 |
| Esc | 取消 |
| 失焦 | 自动保存 |
| 点击行空白处 | 打开该学生详情抽屉 |

修改任一单元格后,KPI 条、分数段、四项达标率、班级进度会**立即重算**。

## 使用

直接用浏览器打开 `index.html` 即可,无需服务器、无需联网。

## 数据

原始数据来自 `成绩表1.xlsx`(40 名学生,含总分、目标分、词汇量、听/读/写分项及弱项诊断)。

## 说明

本仓库为公开仓库,包含学生姓名与成绩数据。
